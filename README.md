# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 技术栈

React + Vite + TypeScript

## 音程复核板

在原有调音记录页下方新增「音程复核板」：按场馆、音栓、八度组织音管，录入实测频率后自动判定纯五度与八度的音分偏差和拍频；重测某根管只清除涉及它的复核结论，其余音程继续有效；仍有超限音程时单次维护报告不能签发。数据只存本机（localStorage）。

业务代码分为三个文件：

- `src/business/intervalJudge.ts` — 音程判定：纯律频率比、音分偏差、共有泛音拍频与阈值
- `src/business/reviewStore.ts` — 记录保存：本机存取、重测时选择性失效、签发门禁
- `src/business/IntervalBoard.tsx` — 页面交互：筛选、录入 / 重测、关联对象、超限过滤与报告签发
