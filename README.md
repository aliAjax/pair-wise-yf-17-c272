# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 技术栈

React + Vite + TypeScript

## 音程复核板

在现有页面下方新增音程复核板：按场馆、音栓和八度组织音管，录入实测频率后比较纯五度与八度的偏差和拍频；重测某根管只清除涉及它的复核结论（上次结论保留），仍有未通过音程时单次维护报告不能签发。数据只存本机 localStorage。

业务拆分为三个文件：

- `src/intervalJudge.ts`：音程判定（纯五度 3:2 / 八度 2:1 的期望频率、音分偏差、拍频与合格判定、音程配对）
- `src/reviewStore.ts`：记录保存（本机持久化、重测失效、结论写入、报告签发拦截）
- `src/IntervalReviewBoard.tsx`：页面交互（筛选超限音程、录入频率、查看关联对象、复核与签发）
